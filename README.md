## Sobre ✨

Este é um projeto open source com uma coleção de desafios de desenvolvimento frontend, criado originalmente pela comunidade CodeLab. A ideia é simples: você escolhe um layout, constrói a interface do seu jeito e pratica o que já sabe (ou o que quer aprender).

## Como usar 🚀

1. Escolha um desafio na tabela abaixo.
2. Abra o layout no Figma.
3. Desenvolva com a tecnologia que quiser: HTML, CSS, JavaScript, React, Vue, Angular ou qualquer outra.
4. Publique o resultado no seu GitHub e use como projeto de portfólio.
